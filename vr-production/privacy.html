개인정보처리방침

이 방침은 운영자 본인의 자료를 위한 IBVR VR Production Backup의 Google 계정 연결과 백업 처리에 적용됩니다. 현재 운영 연결을 준비하는 단계이며, 아래 내용은 연결 후 적용할 데이터 처리 원칙을 포함합니다.

접근하는 정보와 목적

Google Drive의 drive.file 권한으로 앱이 만들거나 사용자가 앱에 연결한 백업 파일과 필요한 메타데이터를 처리합니다. 파일 식별자·이름·폴더 관계·생성 시각·검증용 해시는 저장, 재다운로드 및 복원 검증에 사용합니다.

Drive API로 본인 계정의 이메일을 확인해 지정한 백업 계정과 대조합니다. 다른 계정으로 확인되면 설정을 완료하지 않습니다. Google 비밀번호를 수집하지 않습니다.

암호화할 내용은 운영자 자신의 잔고·주문·체결·입출금·비용 등 전략 운영 기록과 복구에 필요한 설정·구조·버전 정보입니다. 공개 검증 정보에는 원장 원문·계좌번호·비밀번호·인증 토큰·복호화 키를 포함하지 않습니다.

저장과 보호

운영 자료는 운영자가 관리하는 서버에서 암호화한 뒤 전용 Google Drive 폴더에 저장하도록 준비합니다. 복호화 키는 백업 사본과 분리해 운영자가 보관합니다.

OAuth 클라이언트 인증 정보와 갱신 토큰은 접근이 제한된 서버 설정 파일에서 관리하며 공개 웹사이트나 금융 백업 묶음에 넣지 않습니다. 서버의 인증 토큰은 백그라운드 백업을 위한 접근 갱신에 사용합니다. 접근이 철회되거나 인증이 만료되면 오류를 기록하고 재설정이 필요합니다.

복호화·복원 검증은 운영자가 관리하는 격리된 환경에서 수행합니다. 실제 운영 원장을 과거 사본으로 덮어쓰거나 복원을 이유로 주문을 자동 실행하지 않습니다.

외부 제공과 사용 제한

백업은 운영자 본인의 Google Drive에 보관합니다. Google은 저장·전송 서비스 제공자로서 자체 약관과 개인정보처리방침에 따라 데이터를 처리합니다. 이 앱은 데이터를 판매하거나 광고에 이용하지 않으며, 범용 AI 모델 학습에 이용하지 않습니다. 장애 알림에 원장 원문이나 인증 정보를 넣지 않습니다.

Google API로 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

보관·삭제·연결 해제

금융 백업은 운영자가 삭제할 때까지 보관하며, 현재 자동 삭제 기한은 정하지 않습니다. 운영자는 Google Drive에서 해당 백업을 직접 삭제할 수 있습니다. 서버의 로컬 사본과 별도 키 사본은 각각 관리합니다.

Google 계정의 연결 관리에서 앱의 접근을 철회할 수 있습니다. 철회는 이미 저장된 백업이나 로컬 사본을 자동 삭제하지 않습니다. 도구 사용을 종료할 때에는 정기 작업 중지, 서버 인증 정보 제거, 불필요한 사본 정리를 함께 수행해야 합니다.

이 소개 웹사이트

자체 로그인, 파일 업로드, 광고, 방문 분석 스크립트를 사용하지 않습니다. 호스팅 제공자인 GitHub Pages가 보안을 위해 방문자의 IP 주소 등을 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.
