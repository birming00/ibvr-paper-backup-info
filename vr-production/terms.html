용도와 준비 상태

IBVR VR Production Backup은 운영자 자신의 전략 운영 기록을 보관하고 복원을 확인하기 위한 개인용 도구입니다. 현재 운영 인증과 백업 연결을 준비하고 있습니다. 이 소개 페이지를 실제 백업 성공이나 복원 완료의 증거로 사용하지 않습니다.

자신이 관리할 권한이 있는 계정과 자료에만 연결합니다. 공개 회원가입이나 타인의 자료 업로드를 받지 않습니다.

백업과 복원

운영자는 복호화 키를 백업 파일과 분리해 보관하고 실제 복원 결과를 확인해야 합니다. 키를 잃으면 암호화 사본만으로 복원할 수 없습니다.

네트워크 장애·인증 만료·저장공간 부족·외부 서비스 제한 때문에 백업이 실패하거나 지연될 수 있습니다. 최근 성공 시각과 실패 기록을 확인하고 필요한 조치를 수행해야 합니다.

복원은 격리된 환경에서 검증합니다. 백업 도구는 복원을 이유로 실제 주문을 재실행하거나 거래 중지를 해제하지 않습니다.

외부 서비스와 데이터 처리

Google Drive와 GitHub Pages 사용에는 각 제공자의 약관과 서비스 제한이 적용됩니다. 데이터 처리·보관·연결 해제는 개인정보처리방침을 따릅니다.
