개인정보처리방침

이 방침은 IBVR Paper Backup의 Google Drive 연결과 백업 데이터 처리에 적용됩니다. 앱은 운영자 본인이 사용하는 개인용 도구입니다.

접근하는 데이터와 목적

Google Drive의 drive.file 권한을 사용해 앱이 만든 암호화 백업 파일, 검증 정보 및 그 파일의 식별자·이름 등 전송에 필요한 메타데이터를 처리합니다. 목적은 백업 저장, 다운로드, 무결성 확인과 복원 검증입니다.

암호화 파일에는 운영자의 모의투자 거래 기록, 복구 설정과 처리 대기 기록이 들어 있습니다. 검증 정보에는 생성 시각·파일 해시·암호화 형식이 포함되며, 이 검증 정보 자체는 암호화되지 않습니다. 거래 기록의 원문이나 복호화 키는 검증 정보에 넣지 않습니다.

저장과 보호

백업 내용은 운영자의 서버에서 암호화한 뒤 Google Drive로 전송합니다. 복호화 키는 운영자가 별도로 보관하며 Drive 백업에 포함하지 않습니다.

OAuth 인증 토큰과 클라이언트 인증 정보는 서버에서 파일 접근 권한을 제한해 관리하며 백업 묶음·공개 웹사이트에 넣지 않습니다. 내려받은 사본의 복호화·복원 검증은 운영자가 관리하는 개발 환경에서 수행합니다.

공유와 사용 제한

백업은 운영자 본인의 Google Drive에 보관됩니다. Google은 저장·전송 서비스 제공자로서 자체 약관과 개인정보처리방침에 따라 데이터를 처리합니다. 앱은 백업 데이터를 판매하거나 광고에 이용하지 않으며, 범용 AI 모델 학습에 이용하지 않습니다. 백업 내용을 장애 알림 서비스에 전송하지 않습니다.

Google API로 받은 데이터의 사용과 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

보관·삭제·접근 철회

백업은 운영자가 삭제할 때까지 보관하며, 현재 자동 삭제 기간은 설정하지 않습니다. 운영자는 Google Drive에서 해당 백업을 직접 삭제할 수 있습니다. 서버의 로컬 사본은 별도로 관리합니다.

Google 계정의 연결 관리에서 이 앱의 접근을 철회할 수 있습니다. 접근 철회는 기존 백업 파일이나 서버의 로컬 사본을 자동으로 삭제하지 않습니다. 사용을 종료할 때에는 정기 백업을 중지하고 인증 정보와 불필요한 사본을 별도로 정리해야 합니다.

소개 웹사이트

이 소개 페이지에는 자체 회원가입, 파일 업로드, 광고, 방문 분석 스크립트가 없습니다. GitHub Pages 호스팅은 보안을 위해 방문자의 IP 주소를 기록합니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.

문의와 변경
